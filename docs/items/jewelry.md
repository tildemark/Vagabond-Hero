# Vagabond Hero: Jewelry (Neck & Fingers) Item Database

**File:** `item-jewelry.md`
**System:** Equipment Database (Levels 1 - 70)

This document contains the foundational database for all **Neck** (Amulets, Necklaces, Chokers) and **Fingers** (Rings, Bands, Signets) slot items spanning Levels 1 to 70.

*Note: Unlike armor, Jewelry possesses **0 Base Armor**. Their power comes entirely from their high Modifier Budgets, granting massive boosts to Core Stats, Resistances, Critical Hit rates, and Magic Find.*
